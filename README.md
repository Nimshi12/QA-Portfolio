# QA Portfolio

Welcome to my Quality Assurance portfolio.

This repository documents my development of practical software testing skills, testing techniques, and quality assurance practices.

## Portfolio Sections

* **Manual Testing:** Test plans, scenarios, test cases, and execution reports.
* **API Testing:** API validation, negative testing, and response verification.
* **Automation:** Automated testing projects and frameworks.
* **SQL Validation:** Database verification and data integrity checks.
* **Bug Reports:** Structured defect reports with reproduction steps and evidence.
* **Performance Testing:** Performance testing plans and results.
* **Test Plans:** Test strategies, risk assessments, and test planning documents.
* **Exploratory Testing:** Exploratory testing sessions and findings.
* **Learning Journal:** Reflections, challenges, and lessons learned.

## Current Focus

I am building my foundation in software testing, requirements analysis, test design, and defect reporting before progressing to API testing, SQL, and test automation.

## Approach

My focus is on understanding why testing is performed, identifying risks, documenting evidence, and communicating defects clearly.

This portfolio will evolve as I complete practical exercises and projects throughout my QA learning journey.
